# Blueprint — recipes (for the Director)

1. **Fix / refactor film (25 s).** HOOK(hero = the diff) → TITLE → CODE(focus on the change) → DIFF(revision cloud;
   rev B) → TERMINAL(gauge + PASS) → STATS → END(signed + RELEASED). `sheet-slide` between acts, hard cuts inside.
2. **Product film (web app).** HOOK(image hero) → TITLE(general arrangement) → FEATURE ×2 (DETAIL C zoom, callout) →
   SCROLL(elevation) → STATS(measurements) → END. Give SCREEN/FEATURE ≥ 3.3 s so trace → develop → detail all land.
3. **How it was built.** PROBLEM(requirement) → PLAN(process boxes) → MONTAGE(parts list of tool calls) → CODE →
   BEFORE_AFTER(REV A → REV B) → END. `plot-wipe` for the PLAN → MONTAGE turn.
4. **Vertical (9:16).** Same scenes; views stack (REV A over REV B, FEATURE callout below the view), title block stays
   bottom-right. Keep labels ≤ 30 characters.

Rules: redline only for revisions (cloud, delta, strike, REV, FAIL) — never decoration; keep camera moves calm
(drift ≤ 2 %, one detail zoom per shot); plotter cadence on the bed's 8ths (`type` = plotter SFX).
