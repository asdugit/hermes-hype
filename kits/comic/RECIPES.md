# Comic recipes

- **Quick mode**: `style: comic` → every shot is `kit:comic/<TYPE>`; kit.json transitions map `push` →
  `page-turn` (0.7 s, between acts), `wipe` → `splat-iris` (0.5 s, into a payoff: TERMINAL pass, BEFORE_AFTER,
  STATS), `match` → `panel-glide` (0.5 s, same-subject continuity, e.g. SCREEN → FEATURE), `cut` → hard cut on a
  beat (the comic default inside an act).
- **Openers**: HOOK is a splash page — feed it the single strongest artefact (green test run → PASS!, product
  screenshot → BOOM!, diff → SHNK!) and a ≤ 6 word label. TITLE is the issue cover: title, tagline ribbon,
  optional one-liner blurb; keep the title ≤ 12 characters for the biggest masthead.
- **The story beats**: PROBLEM (user prompt verbatim in a balloon, agent panels "reads it / gets to work") →
  PLAN (caption-box checklist with check stamps and NOW!) → CODE / DIFF (agent at the keys, the real file inked
  in, camera pushes onto the focus lines) → TERMINAL (frame-B page: typing panel, inked terminal, PASS!/DONE!
  splash) → SCREEN / FEATURE / SCROLL (printed screenshots, LOOK! / CLICK! / SWOOSH!) → BEFORE_AFTER (grey
  before, KRAK! lightning gutter, full-colour after) → STATS (numbers in bursts on a sunburst) → END (back cover).
- **Quotes**: CALLOUT with `who: user` speaks from the reader silhouette (magenta rim), `agent` from the hero bust,
  `test` or a line ending in `!` becomes a jagged shout balloon.
- **Pacing**: comic reads best at 3–5.5 s per page; balloons need ≥ 0.3 s per phrase; let a slam land on a beat
  (cues `hit` / `pass` are placed on the slam frame, the music sync snaps them).
- **9:16**: same params; SCREEN / FEATURE automatically switch to establishing + close-up panels; keep feature
  names ≤ 5 words (two lines of 92 px lettering).
- **Don't**: mix the comic page with a dark kit shot in the same film (the newsprint world breaks); use more than
  one onomatopoeia per panel; put long prose in balloons (> 30 words → use the TERMINAL or CODE page instead).
