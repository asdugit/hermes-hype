# Cinematic kit — critique log

## v1 (all 16 scenes, real runtime, GPU 1080p keyframes at t≈2.2 s of 3 s shots)
Every scene renders (no black/empty tiles, no scene errors). Reads like the approved style frames: dark room,
emissive glass cards, per-card DOF, dust bokeh, 2.39 letterbox with the session rail, amber accent only.
- TITLE/END: corridor + wide-tracked Cormorant title + italic tagline — strong.
- HOOK/SCREEN/FEATURE/SCROLL: screenshot card lit and sharp, italic caption + kicker + URL lower third.
- PLAN/CODE/DIFF/TERMINAL: legible at 1080p; CODE 3/4 with the amber focus gutter; TERMINAL PASS line blooms.
- STATS: big Cormorant numbers between defocused cards; CALLOUT: centred italic quote.
- BEFORE_AFTER: before card cold/defocused left, after card warm/sharp; one flare sweep at the rack.
Weak spots: short terminal cards (1–2 lines) are small in BEFORE_AFTER; MONTAGE chips small at 3 s;
type is drawn into an overlay texture, so it is not registered with the runtime's text QA.
